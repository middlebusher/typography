Shadows & Effects
--inset-shadow-cui-border
inset 0 0 0 1px oklch(border-tint / 6%)
Subtle border on any surface — adapts between light and dark themes
--inset-shadow-cui-button
inset 0 1px 0 0 white / button-highlight-alpha
Top highlight on buttons — 40% in light, 12% in dark
--inset-shadow-cui-primary
inset top highlight 15% + bottom shadow 15%
Primary CTA button depth — top gloss + bottom shadow
Inset shadow strategy: All shadows are inset box-shadows applied to the element itself, not drop shadows. This keeps them contained to the component boundary and avoids z-index conflicts in stacked UIs like the PR review panel.

--animate-cui-dot-cycle
cui-dot-cycle 1.2s steps(1) infinite
Ellipsis loading indicator
Duration guidelines:
  • Micro interactions (hover, focus): 100–150ms
  • Element entrances (popover, menu): 200ms
  • Page transitions, panels: 250–350ms
  • Never animate beyond 400ms for UI — use longer only for ambient / illustrative motion
