Brand Colors — Chromatic Color Budget
These percentages define the maximum share of any screen that high-chroma color should occupy — not brand importance. The remaining ~80% is neutral (mauve scale). This constraint keeps the UI calm and ensures that when chromatic color appears, it registers as a signal rather than decoration.
Orange · 15% — CTAs, focus rings, active states, key data points. The only color that should trigger "do something."
Green · 2.5% — Success states, passing checks, approved reviews. Appears sparingly so it always reads as positive confirmation.
Purple · 2.5% — AI-generated content, code insights, suggestion highlights. Visually distinct from action and success.

  • Element entrances (popover, menu): 200ms
  • Page transitions, panels: 250–350ms
  • Never animate beyond 400ms for UI — use longer only for ambient / illustrative motion
Design Principles
01
Clarity over cleverness
Every element should communicate its purpose instantly. Code review is already cognitively dense — the UI must reduce load, not add to it. Decorative complexity is waste.
02
Signal, not noise
Orange is reserved for actions that matter. Status colors carry meaning. Use emphasis sparingly so that when something needs attention, it gets it — not lost in a wall of highlights.
03
Speed as a feature
Developers measure in keystrokes. Transitions must feel instantaneous — entrances under 200ms, exits under 150ms. Never let animation delay a workflow.
04
Precision in type
Tight letter-spacing at display size, open tracking at caption size. Line height that breathes at body scale, compressed at hero scale. Typography is not decoration — it is the product.
05
Dark-first, not dark-only
The mauve scale is perceptually balanced across light and dark. Design in dark, verify in light. Semantic tokens abstract away the theme — components should never hard-code scale steps.
06
Composable tokens
No component should reference a raw scale value like mauve-7 directly. All color, spacing, and shadow decisions go through the semantic token layer — this is what makes theming possible.
Figma Reference — Letter Spacing Conversion
Figma uses %, not em. Multiply the em value × 100. Titles track tight (negative); body and small copy track open (positive).
−0.022em = −2.2% · titles 4–9 −0.012em = −1.2% · titles 1–3
0em = 0% · text-large +0.005em = +0.5% · text-regular +0.01em = +1.0% · text-small
+0.015em = +1.5% · text-mini +0.02em = +2.0% · text-micro +0.03em = +3.0% · text-tiny
